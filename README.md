# 🌍 Weather and Air Quality Visualization

This project is a web-based interactive data visualization tool for exploring weather and air quality data of cities across the world. Built using HTML, JavaScript
, D3.js, and Leaflet.js, it provides both map-based and graphical insights.

---

## 🚀 Features

- 🗺️ **Map View** (`map.html`)
  - Visualizes AQI and weather data using interactive map markers.
  - Uses Leaflet.js and Marker Clustering for smooth interaction.
  - AQI markers show detailed pollutant data (CO, PM2.5, NO2, etc.).
  - Weather markers display temperature, wind speed, and descriptions.

- 📊 **Graphs View** (`graphs.html`)
  - D3.js charts visualize:
    - Top 15 cleanest cities (least AQI)
    - Top 15 most polluted cities (most AQI)
    - Wind speed vs. temperature scatter plot
  - Includes interactive tooltips and axis labels.

- 🎯 **Landing Page** (`index.html`)
  - Simple UI to switch between Map and Graph views.
